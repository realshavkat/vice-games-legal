Politique de confidentialité

Dernière mise à jour : 1 août 2026 · Service : bot Discord « Vice Games »

1. Qui nous sommes

La présente politique décrit comment Vice Games (« nous ») traite les données lors de l'utilisation du bot Discord Vice Games (le « Bot »). Contact : vicegames.support@gmail.com.

2. Données que nous traitons

Selon la configuration du serveur, nous pouvons traiter :

  • Identifiants Discord — ID de serveur (guild), ID de salon, ID de rôle, ID utilisateur (lorsque nécessaire pour une commande ou un paramètre).
  • Configuration du Bot — préférences d'alertes, boutiques suivies, types d'offres, langue, devise, mots bloqués, salons de diffusion.
  • Contenu de commandes — textes saisis dans les commandes slash ou interactions (ex. filtres, mots-clés), le temps nécessaire au traitement.
  • Logs techniques — horodatages, codes d'erreur, métadonnées d'exécution pour diagnostiquer des incidents (sans stocker le contenu des messages de salon de façon générale).

Nous ne demandons pas de mot de passe Discord, de données bancaires, ni de documents d'identité.

3. Finalités

  • fournir les fonctionnalités du Bot (alertes, listes d'offres, paramètres) ;
  • mémoriser la configuration choisie par les administrateurs ;
  • assurer la sécurité, prévenir les abus et corriger les bugs ;
  • répondre aux demandes de support.

4. Base légale

Selon votre situation, le traitement repose sur l'exécution du service demandé (utilisation du Bot), notre intérêt légitime à faire fonctionner et sécuriser le service, et/ou votre consentement lorsque la loi l'exige.

5. Conservation

Les données de configuration sont conservées tant que le Bot reste présent sur le serveur ou jusqu'à suppression à votre demande. Les logs techniques sont conservés pour une durée limitée (en pratique quelques semaines), sauf besoin plus long lié à un incident de sécurité. Après retrait du Bot, les données associées peuvent être effacées lors des cycles de nettoyage.

6. Destinataires et sous-traitants

Les données peuvent être hébergées chez des prestataires d'infrastructure (hébergeur du Bot, base de données) agissant selon nos instructions. Discord reçoit les interactions que vous envoyez via son API dans le cadre normal d'un bot. Nous ne vendons pas vos données.

7. Transferts

Selon l'hébergement choisi, des données peuvent être traitées hors de votre pays de résidence. Dans ce cas, nous veillons à des garanties appropriées lorsque la réglementation l'exige.

8. Sécurité

Nous appliquons des mesures raisonnables (contrôle d'accès, journaux, limitation des permissions Discord demandées) pour protéger les données. Aucun système n'est totalement sécurisé.

9. Vos droits

Selon la réglementation applicable (notamment RGPD pour l'EEE), vous pouvez demander l'accès, la rectification, l'effacement, la limitation ou la portabilité de vos données, et vous opposer à certains traitements. Contactez vicegames.support@gmail.com en précisant votre ID Discord et le serveur concerné. Vous pouvez également introduire une réclamation auprès de votre autorité de protection des données (en France : CNIL).

10. Mineurs

Le Bot s'adresse à des utilisateurs autorisés à utiliser Discord. Nous ne collectons pas sciemment de données auprès d'enfants en dehors du cadre imposé par Discord.

11. Liens tiers

Le Bot peut renvoyer vers des boutiques ou sites tiers (Steam, Epic, etc.). Leurs politiques de confidentialité s'appliquent dès que vous quittez notre service.

12. Modifications

Cette politique peut être mise à jour. La date indiquée en tête de page reflète la version en vigueur. L'usage continu du Bot après publication vaut prise de connaissance de la version à jour.

13. Contact

Questions vie privée : vicegames.support@gmail.com.
